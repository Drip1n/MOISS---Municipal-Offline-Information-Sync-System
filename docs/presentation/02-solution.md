# Solution

MOISS is an offline store-and-forward communication system. Municipal updates
are signed, stored digitally, and physically carried by couriers between
disconnected locations. **The courier becomes the transport layer of the network.**

> ## "When the network stops moving data, we move the data."

## Key value

- No internet required
- No cellular infrastructure required
- Uses existing human logistics — couriers on foot or bike
- Information stays authenticated — every update is cryptographically signed

## What we are *not* claiming

MOISS is **not** a replacement for C2000, NL-Alert, or a complete disaster
communication system.

MOISS **is** a fallback synchronization layer between disconnected municipal
locations.
